# RST Workshop - Germany 2020[#](#rst-workshop-germany-2020 "Link to this heading")

This workshop has two components:

> 1. Writing documentation using reStructuredText (RST)
> 2. Setting up a Sphinx server

Afterwards, follow the instructions to set up a Sphinx server for
your documentation. Or, just build a Docker images using the template
`Dockerfile`. There are two variations:

> 1. Debian - Well supported packages, stable
> 2. Alpine - Small footprint
