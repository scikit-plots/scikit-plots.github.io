# C Programming[#](#c-programming "Link to this heading")

These labs provide the learners with practical experience as they learn
about C programming.

> **Note**
> Some labs are platform independent using Windows or POSIX (Linux), but
other labs require POSIX.

* See [Windows 10: Setup C Environment](windows-install/index.html#windows-10-c-environment) on how to set up Windows 10 to compile
  and execute C.
* Write and compile code online at [ide.judge0.com](https://ide.judge0.com/) in a POSIX
  environment.
