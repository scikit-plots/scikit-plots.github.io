# Lab 8: Overview[#](#lab-8-overview "Link to this heading")

This lab shows methods of deleting (unlinking) a file or
erasing data in an existing file.

## Lab 8 Resources[#](#lab-8-resources "Link to this heading")

* [unlink](https://docs.microsoft.com/en-us/cpp/c-runtime-library/reference/unlink-wunlink?view=vs-2019) function (Microsoft)
* [remove](https://docs.microsoft.com/en-us/cpp/c-runtime-library/reference/remove-wremove?view=vs-2019) function (Microsoft)
* [open](https://docs.microsoft.com/en-us/cpp/c-runtime-library/reference/open-wopen) function (Microsoft)
* [open](http://codewiki.wikidot.com/c:system-calls:open) function (Code Wiki)

## Goals for Lab 8[#](#goals-for-lab-8 "Link to this heading")

During this lab, you will learn how to use:

> 1. `unlink()` to delete a file.
> 2. `remove()` to delete a file.
