# [7.1. Terminating a Process Forcefully](#id1)[#](#terminating-a-process-forcefully "Link to this heading")

Terminating a process in Windows using `TerminateProcess()` requires
the process handle, which can be acquired using the process ID. The
procedure uses these three functions:

[OpenProcess](https://docs.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-openprocess)
:   Use the PID to acquire the process handle from an existing process

    ```
    HANDLE OpenProcess(
        DWORD dwDesiredAccess,  // Flags to control access to the process object.
        BOOL  bInheritHandle,   // Inherit handle
        DWORD dwProcessId       // Process ID to access
    );

    ```

[TerminateProcess](https://docs.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-terminateprocess)
:   Terminates the process and all of its threads using the process handle

    ```
    BOOL TerminateProcess(
        HANDLE hProcess,    // A handle to the process to be terminated.
        UINT   uExitCode    // The exit code that the process will return
    );

    ```

[CloseHandle](https://docs.microsoft.com/en-us/windows/win32/api/handleapi/nf-handleapi-closehandle)
:   Release the process handle

    ```
    BOOL CloseHandle(
        HANDLE hObject
    );

    ```

> **Caution**
> * Using function `TerminateProcess()` terminates the process
  immediately.
* It does not do it gracefully.
* It is equivalent to unplugging the power from your computer
  instead of using the shutdown procedure.

## [TerminateProcess() Template Code](#id2)[#](#terminateprocess-template-code "Link to this heading")

****Required Include Files****

> ```
> #include <windows.h>
>
> ```

****Basic Usage****

> ```
> DWORD pid;
> HANDLE process_handle;
>
> pid = 99999;
>
> process_handle = OpenProcess(SYNCHRONIZE | PROCESS_TERMINATE, TRUE, pid);
> TerminateProcess(process_handle, 0);
>
> CloseHandle(process_handle);
>
> ```

## [7.1.2. Task: Terminate Process](#id4)[#](#task-terminate-process "Link to this heading")

Next, terminate a process using a valid process ID

1. Start notepad.exe and add some text.

   1. Press the X button to close the windows and verify that the **Save
      Dialog** window displays. Press Cancel to close the dialog   
      ![image0](../../../../../_images/notepad-save-as.png)
2. Open the **Task Manager** and locate the PID.
3. Use your code to terminate the process using the PID.
4. Verify that notepad closes without prompting the user to save the
   file

You can see that using `TerminateProcess()` closes an application in a
way that is not safe. There are better shutdown methods that wait for the
application to perform any cleanup code or to send a shutdown signal so
the process can exit gracefully.
