## [Snaps](#id6)[#](#snaps "Link to this heading")

A `.snap` package for the Ubuntu Core system contains all its dependencies.
The packages ensure that the app will always have the proper dependencies and
software versions.

> * Importantly, `snaps` ensure that a system update to an underlying
>   process, such as a Python update, won’t break the application.

Read more:

> * [Complete Guide for Using Snap Packages In Ubuntu and Other Linux Distributions](https://itsfoss.com/use-snap-packages-ubuntu-16-04/)
> * [Basic tutorial by Ubuntu](https://tutorials.ubuntu.com/tutorial/basic-snap-usage)
> * [Snapcraft: The app store for Linux](https://snapcraft.io/)

We will install [Rocket.Chat](https://rocket.chat/), which is an open-source team
communication tool. Tools like this are great because you are
in control of your own data, not some big company that makes
money by selling your information to the highest bidder or
restrict your data due to their policy.

The [manual install instructions for Rocket.Chat](https://rocket.chat/docs/installation/manual-installation/ubuntu/) requires the
user to install MongoDB, Node.js, and other dependencies. Then, the
user has to configure the service with specific settings. The
commands aren’t complicated, but they aren’t guaranteed to work
if a different version of a dependency. The [snap version of Rocket.Chat](https://rocket.chat/docs/installation/manual-installation/ubuntu/snaps/)
installs using a single command. We do not need to be concerned
with any dependencies or misconfiguration of the application.

Here are some basic snap commands. The [Basic tutorial by Ubuntu](https://tutorials.ubuntu.com/tutorial/basic-snap-usage) has
more information. These commands use `hello-world` for the sample snap.

View the snap commands using `snap help --all`

### [Basics (basic snap management)](#id8)[#](#basics-basic-snap-management "Link to this heading")

1. `snap find hello` searches the snap repository for anything containing
   the text `hello`
2. `snap install hello-world` installs the `hello-world` snap
3. `snap list` displays the snaps installed on the system
4. `snap remove hello-world` removes the `hello-world` snap from the system
5. `snap info hello-world` displays information about the `hello-world`
   snap package
6. `snap refresh hello-world` manually checks for updates about to the
   `hello-world` snap
7. `snap enable hello-world` enables the `hello-world` snap.
8. `snap disable hello-world` disables the `hello-world` snap.

### [Daemons (manage services):](#id9)[#](#daemons-manage-services "Link to this heading")

1. `snap services` displays the status of services
2. `snap start hello-world` start the `hello-world` snap.
3. `snap stop hello-world` stop the `hello-world` snap.
4. `snap restart hello-world` restart the `hello-world` snap.
5. `snap logs hello-world` retrieve the logs for the `hello-world` snap.

## [Rocket.Chat](#id10)[#](#rocket-chat "Link to this heading")

We will follow the installation instructions for the
[snap version of Rocket.Chat](https://rocket.chat/docs/installation/manual-installation/ubuntu/snaps/).

1. Install Rocket.Chat using `snap`

   ```
   sudo snap install rocketchat-server

   ```
