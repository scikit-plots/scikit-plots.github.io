# [Step 4: Configure the firewall](#id2)[#](#step-4-configure-the-firewall "Link to this heading")

## [Firewall Overview](#id3)[#](#firewall-overview "Link to this heading")

Securing your VPS is very important. Configuring a firewall
is an easy way to provide a lot of security.

* A firewall allows you to control incoming and outgoing traffic.

Initially, we will allow outside traffic to enter the VPS using
ports 80 (HTTP), 443 (HTTPS), and 22 (SSH). We won’t restrict outgoing
traffic to keep the procedure simple. Ultimately, we want to restrict
outgoing traffic, as well.

* We will use Ubuntu’s [Uncomplicated Firewall](https://help.ubuntu.com/community/UFW) because it is not
  complicated and easy to use. :)).
* This guide was modified using instructions from DigitalOcean’s guide on
  [how to set up a firewall](https://www.digitalocean.com/community/tutorials/how-to-set-up-a-firewall-with-ufw-on-ubuntu-18-04).

## [Configuring the Firewall](#id5)[#](#configuring-the-firewall "Link to this heading")

Let’s practice straight away using `nano`!

### [Verify that IPv6 is enabled](#id6)[#](#verify-that-ipv6-is-enabled "Link to this heading")

Most VPSs provide an IPv6 address. Furthermore, it should be enabled by
default on UFW. But, let’s verify.

To open the file using `nano`, we must supply the full path or
just the file name. The file that we want to open is
`/etc/default/ufw`.

> * `/etc/default` is the path to the file.
> * `ufw` is the name of the file.

```
sudo nano /etc/default/ufw

```

* Shell scripts or bash use `#` for comments.
* Using your arrow, keys, navigate to a line that has the configuration
  of `IPV6=yes`.

  > * If you see `#` character in front of it, delete it.
* Save and exit the file using `Ctrl+S Ctrl+X`

### [Configure UFW](#id7)[#](#configure-ufw "Link to this heading")

1. Set the firewall to `deny all` incoming connection

   ```
   sudo ufw default deny incoming

   ```

2. Set the firewall to `allow all` outgoing connections

   ```
   sudo ufw default allow outgoing

   ```
3. We will restrict the firewall to allow SSH (port 22), HTTP (80), and
   HTTPS (443) through the firewall. All other ports will be blocked.

   ```
   sudo ufw allow ssh
   sudo ufw allow http
   sudo ufw allow https

   ```
4. Enable the firewall rules now and also on system restart

   ```
   sudo ufw enable

   ```

### [Reboot and Verify](#id8)[#](#reboot-and-verify "Link to this heading")

On some systems, UFW does not automatically enable on reboot.
We should test it.

```
sudo reboot -n

# after logging back in, verify:
sudo ufw status verbose

```

If the firewall is disabled, you need to enable it using
`systemctl` (system control)

```
sudo systemctl enable ufw

```
