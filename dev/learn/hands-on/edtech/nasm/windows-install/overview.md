# [Lab 1: Overview](#id1)[#](#lab-1-overview "Link to this heading")

The first lab will guide you to set up your computer so you can compile
and execute assembly code!

The assembly programming environment consists of three components, which are:

1. A code editor: [Visual Studio Code](https://code.visualstudio.com/)
2. A C/C++ compiler: [MinGW](http://www.mingw.org/)
3. An assembler: [Netwide Assembler (NASM)](https://www.nasm.us/)

****Additional Resources****

* [Paul Carter's reference site](https://pacman128.github.io/pcasm/)

## [Goals for Lab 1](#id2)[#](#goals-for-lab-1 "Link to this heading")

During this lab, you will learn how to:

> 1. ****Setup**** your assembly programming environment.
> 2. ****Compile**** an `.asm` (assembly code file) source file.
> 3. ****Create**** an `.exe` file.
