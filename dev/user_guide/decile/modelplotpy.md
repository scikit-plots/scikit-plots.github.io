# ModelPlotPy[#](#modelplotpy "Link to this heading")

This module contains functions related to [`decile`](../../apis/scikitplot.decile.html#module-scikitplot.decile "scikitplot.decile") and legacy [`modelplotpy`](../../apis/scikitplot.decile.html#module-scikitplot.decile.modelplotpy "scikitplot.decile.modelplotpy").

The [`ModelPlotPy`](../../modules/generated/scikitplot.decile.ModelPlotPy.html#scikitplot.decile.ModelPlotPy "scikitplot.decile.ModelPlotPy") class dataframe helper to build nice plots to explain
your modelling efforts easily to business colleagues.

> **See also**
> * [modelplot/modelplotpy](https://github.com/modelplot/modelplotpy/blob/master/modelplotpy/functions.py)
* <https://modelplot.github.io/intro_modelplotpy.html>
