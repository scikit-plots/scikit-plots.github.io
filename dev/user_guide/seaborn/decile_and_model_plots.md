# Decile and model plots[#](#decile-and-model-plots "Link to this heading")

`decileplot` uses decile-oriented features and labels to visualize
response/lift/gain-style behavior. `modelplot` is the more general
high-level model plotting entry point.

`print_labels` documents the decile table feature vocabulary, including
response counts/rates, cumulative gain/lift and KS-related fields. Use that
legend when interpreting generated tables instead of guessing from abbreviated
column names.

For more direct decile statistics and business plots, see
[Decile analysis](../decile/index.html#decile-index).
